# Colleen & Spencer — St. Augustine Wedding Weekend

A mobile-friendly lodging comparison for the January 29–30, 2027 wedding weekend.

## Publish with GitHub Pages

1. Create a new GitHub repository named `st-augustine-wedding`.
2. Upload `index.html` from this folder to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. After GitHub publishes it, the site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/st-augustine-wedding/`

The Vrbo and hotel buttons in the page are clickable.
